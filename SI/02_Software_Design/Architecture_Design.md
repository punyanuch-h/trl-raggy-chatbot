# Architecture & Software Design: Raggy Bot

## Overview
This document will serve as the formal software design specification for the Raggy Bot API, in compliance with ISO/IEC 29110. It will be updated progressively during Sprint 1 when the primary skeleton is implemented.

## 1. High-Level Architecture
*   **Microservice Framework**: FastAPI
*   **Operating Port**: `8001`
*   **Database**: Pinecone (Serverless)
*   **LLM Engine**: OpenAI (via LangChain orchestration)

## 2. API Specifications (OpenAPI/Swagger)
The OpenAPI specifications for the `/raggy/trl` endpoint have been successfully generated by FastAPI and are definitively exported to the root of this folder as `openapi.json`. This JSON document serves as the formal interactive specification for the API.

## 3. JWT Security & Auth Flow
FastAPI's internal Security middleware has been built and attached to the endpoint relying on `PyJWT`. 
The system extracts the incoming JWT via the `Authorization: Bearer` header. The token is mechanically verified via a symmetric `HS256` algorithm utilizing the local `JWT_SECRET` `.env` variable. Decoded `role` claims map directly to the API's query engine, with missing or malformed claims safely downgrading the user's access directly to `researcher`.

## 4. Data Ingestion Pipeline (Sprint 2)
The system implements a structured ingestion process:
- **Parser**: Uses `pdf_parser.py` (PyPDF) with recursive directory scanning. Documents in `source/private/` are automatically tagged with `{"access": "private"}` metadata.
- **Chunker**: Employs `RecursiveCharacterTextSplitter` (1000 size, 150 overlap).
- **Embedder**: Generates 1536-dim vectors via `text-embedding-3-small`.
- **Vector Store**: Upserts to Pinecone with RBAC metadata injection (private docs get `role: admin` tags).

## 5. RAG Retrieval & Prompting (Sprint 3)
The generative engine follows a strict "Chain of Thought" design:
- **RBAC Retriever**: Any user with `researcher` role has a metadata filter `{"role": {"$ne": "admin"}}` appended to vector search results to prevent data leakage.
- **System Prompt**: A "Master Template" enforcing a polite healthcare persona and strict context-only answering rules.
- **Generative Chain**: Orchestrated via LangChain's `create_retrieval_chain`, combining Pinecone retrieval with OpenAI `gpt-4o-mini` synthesis.
